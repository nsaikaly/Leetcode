# Interview Study Notes

A small collection of study notes for technical interview prep, covering data structures & algorithms (DSA) and system design. Everything is plain Markdown — just open the files and read.

## What's inside

- **[neetcode_cheatsheet.md](neetcode_cheatsheet.md)** — Algorithm templates in Python, organized by pattern (arrays, two pointers, sliding window, graphs, and more). The idea is to learn each template well enough to write it from memory. Follows the [NeetCode Roadmap](https://neetcode.io/roadmap).

- **[system_design.md](system_design.md)** — Core system design concepts and example designs (building blocks, tradeoffs, and how to sketch common architectures).

- **[schedule.md](schedule.md)** — A suggested study plan (~2 hours/day, 4 days/week) that ties the two together over about 5 months.

## How to use it

1. Pick a topic from the cheatsheet.
2. Read the notes until the logic clicks.
3. Close the file and rewrite it from memory.
4. Practice the linked problems without looking back.

That's it — no setup, no installation. It's just notes.
